# ADR (Architecture Decision Record)

Immutable single decision: one per file, dated, never edited after acceptance — a reversal is a new ADR that supersedes this one. Keep it short.

```markdown
# ADR <NNN>: <decision>

- **Status:** proposed | accepted | superseded by ADR-<NNN>
- **Date:** <YYYY-MM-DD>

## Context
<The forces that made this a decision worth recording.>

## Decision
<What was chosen.>

## Consequences
<What it makes easier, harder, or rules out.>
```
